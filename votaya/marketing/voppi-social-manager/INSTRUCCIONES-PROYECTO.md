# Cómo usar el gestor de redes de voppi! en Claude

## Opción A — Como habilidad (skill)
1. En claude.ai: **Ajustes → Capacidades → Habilidades** (Skills) → **Subir habilidad**.
2. Sube el archivo `voppi-social-manager.zip`.
3. Desde cualquier conversación: «Hazme el TikTok de mañana de voppi!», «Calendario de la semana 2», «Presentación de voppi! para la bio».

## Opción B — Como proyecto
1. En claude.ai: **Proyectos → Crear proyecto** → nombre «voppi! · Redes sociales».
2. En **Instrucciones del proyecto**, pega todo el contenido de `SKILL.md` (sin el bloque inicial entre `---`).
3. En **Conocimiento del proyecto**, sube `references/marca.md`, `references/formatos.md` y `references/lanzamiento.md` (y, si quieres, el logo).
4. Abre conversaciones dentro del proyecto para cada tarea de contenido.

## Consejos
- Pásale los resultados reales de la web (capturas o cifras del panel de administración) para que haga los vídeos de resultados.
- Si tienes Higgsfield conectado, pídele que genere las imágenes o vídeos directamente.
- Revisa siempre antes de publicar: el contenido final es responsabilidad de quien lo publica.
